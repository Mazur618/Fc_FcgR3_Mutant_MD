# Archived exploration

These scripts preserve the earlier MM/GBSA ranking, surface/BSA, plotting,
trajectory-checking, and analysis-submission workflows for historical reference.
The supported analysis is `../analysis_v2`; use the root reproduction guide.

Definitions differ from the current workflow (including references, atom masks,
and sampling). Legacy BSA has invalid observations; implied affinity folds and
uncertain rankings must not be treated as primary conclusions. Paths and script
calls assume the old working layout. These are reference copies, not a supported
standalone pipeline. Some commands overwrite outputs or submit jobs; do not run
them over existing data.

Original local copies remain in their historical locations but are excluded from
Git. Moving them out of the publication source selection does not remove data.
